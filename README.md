# Alzheimer's Disease Classification (Machine Learning)

## Problem
Predict whether a patient has Alzheimer’s disease using clinical and cognitive test data.

## Dataset
Clinical diagnosis, cognitive scores (CDRSB, ADAS, MMSE, RAVLT), and brain measurements.

## Methods
- Data preprocessing
- Feature engineering
- Train-test split
- Random Forest classifier

## Evaluation
Model evaluated using accuracy and confusion matrix.

## Tools
Python, Pandas, Scikit-learn, Matplotlib
